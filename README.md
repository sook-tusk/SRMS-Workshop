# SRMS-Workshop

This workshop provides practical and structured guidance on the automation of reporting using R.

The session aims to equip participants with practical skills to enhance research transparency and to improve the quality of research, particularly for those who are non-LaTeX users. 

The content is designed for readers with limited computing experience and aims to provide clear, step-by-step guidance.

# Contents
-	Compiling a report in RStudio (for intermediate processing)
-	Exporting a results table in RStudio to Word
-	Automatic referencing and numbering of tables and figures in Word
-	Exporting R code to Word with syntax highlighting
- Introduction to Quarto and QMD workflow using R
- Introduction to Rmarkdown workflow
- Using RStudio to connect to Github and share a project online
- Using Visual Studio Code (VS Code) to publish a project to Github 

For those who are motivated to share their project files online and showcase their work using RStudio, visit [RStudio-Github-Remote Connection](RStudio-Github-Remote-Connection/SettingUp_Github_RStudio.md). 

If you are familiar with VS Code, you may find [VSCode-Github-Remote-Connection](VSCode-Github-Remote-Connection/SettingUp_Github_VSCode.md) useful.

# Downloading materials (option 1: simpler)

In the SRMS-workshop repository, click **Code** (highlighted in **green**). Select Download ZIP from the dropdown menu. Once the download is complete, unzip and move the contents to the appropriate folder. 

# Downloading materials (option 2)

Alternatively, you could clone the Repository in RStudio. Follow the steps below:

1) Launch **RStudio**
2) Click **New Project...** (located at the top-right corner)
3) Select **Version Control**
4) Then, select **Git**
5) You'll see two blank fields(boxes). Pay attention to the first field, **Repository URL**.

Paste the GitHub repository URL, *https://github.com/sook-tusk/SRMS-Workshop*, into the Repository URL field.

6) Confirm your subdirectory where the cloned repository will be placed.
7) Once everything looks good, click **Create Project** to complete the process.
